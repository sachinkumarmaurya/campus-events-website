# campus-events-website
A  college event website built with HTML and CSS, featuring upcoming events and registration

## Project Description

A simple responsive event management landing page designed for a college web development recruitment task.

## Technologies Used

* HTML5
* CSS3

## Features

* Responsive navigation
* Hero section
* About section
* Upcoming events section
* Event registration form
* Contact section
* Responsive design
* CSS hover effects
* CSS transitions
* Smooth scrolling

## Project Structure

Campus-Events/

├── index.html

├── style.css

└── README.md

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Notes

This project uses only HTML and CSS.

JavaScript is intentionally not used.

The registration form is a front-end form and does not connect to a backend database.
